# 志雄 · 图解信息卡

志亚科技出品。将文章、公众号内容和已确认观点转为高密度图解信息卡，交付 PNG 与可编辑排版源文件。强调图形关系、清晰判断和可独立阅读。

## 使用方式

1. 阅读 [Skill 说明](SKILL.md)，确认输入材料与适用边界。
2. 将包含 SKILL.md 的目录及配套文件放入支持 Skills 的工具目录。
3. 提供自己的材料与目标，按 Skill 的流程执行，并检查实际输出。

配套参考文件与模板需随 Skill 一同保留。
